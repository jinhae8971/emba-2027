# EMBA 2027 봄학기 입학 준비 대시보드

서울대학교 EMBA · KAIST Executive MBA 2027학년도 봄학기 지원을 위한 개인용 준비 대시보드입니다.
빌드 도구·외부 의존성 없이 동작하는 단일 HTML 파일이며, GitHub Pages 정적 호스팅으로 모바일에서도 접근할 수 있습니다.

**공개 주소:** https://jinhae8971.github.io/emba-2027/

## 구성

| 탭 | 내용 |
|---|---|
| 개요 | 히어로 D-Day 카드(다음 마감 + 그 다음 일정), **빠른 등록**(할 일 / 일정 토글), **지금 해야 할 일**(2주 내 마감 자동 수집), 최우선 액션 5, 영역별 진척 막대, 다가오는 일정, 전체 타임라인, **백업 내보내기·복원·초기화** |
| 체크리스트 | 내 할 일 관리, **미완료만 보기** 필터, 서울대(15) / KAIST(12) / 공통 서류(10), 추천인 트래커(행 추가·삭제) |
| 자기소개서 | 스토리라인 6블록 작성(블록별 글자 수 표시), **집중 모드**, 퇴고 체크리스트 10항목, 텍스트 내보내기 |
| 면접 Q&A | 18문항 5개 카테고리, **연습 모드 + 90초 타이머**(문항 이동·진행 도트), 답변 스크립트 작성(글자 수 → 예상 발화 시간), 면접 준비물 체크, 내보내기 |
| 비용 | 회사 지원율 프리셋(100/70/50/0%), 서울대 EMBA · KAIST EMBA · KAIST PMBA 3안 비교, 본인 실부담·월 평균·중도 퇴사 시 반환 위험액 |
| 학교 비교 | 지원자격·전형일정·재학생 프로필(경력·산업 분포 막대) |

## 긴급도 표시

모든 항목의 마감 배지는 6단계로 색이 바뀝니다.

기한 지남(경고 아이콘) · 3일 이내 · 10일 이내 · 30일 이내 · 그 외 · 기한 없음

## 저장 방식

입력한 모든 값(체크박스, 등록한 일정·할 일, 추천인, 자기소개서, 면접 답변, 비용 설정, 마지막으로 본 탭, 필터 상태)은 **브라우저 localStorage**(`emba2027_v1`)에 저장됩니다.

- 서버로 전송되지 않으며 기기 밖으로 나가지 않습니다.
- 같은 기기·같은 브라우저에서만 유지됩니다. (PC와 휴대폰은 별도 저장)
- 시크릿 모드나 브라우저 데이터 삭제 시 사라집니다.
- 체크리스트 항목 수가 바뀌어도 기존 체크는 보존됩니다(비파괴 `fit()`).
- **개요 탭 하단의 "백업 파일 내보내기"** 로 JSON을 저장해 두면 기기 간 이동·복구가 가능합니다. 복원은 같은 자리의 "백업 복원"에 JSON을 붙여넣습니다.
- "전체 기록 초기화"는 되돌릴 수 없습니다.

## 모바일

- 반응형 레이아웃 (표는 가로 스크롤, 하단 6칸 탭 바 고정)

## 콘텐츠 수정

`index.html` 의 스크립트 상단 **① 콘텐츠 데이터** 블록만 교체하면 일정·체크리스트·문항이 모두 갱신됩니다.

`LISTS`(체크리스트 6종) · `EVENTS`(타임라인) · `DDAY`(D-Day 카드) · `EBLOCKS`(자소서 블록) · `QCATS`/`QS`(면접 문항) · `CMP_EXP`/`CMP_IND`(재학생 프로필)
