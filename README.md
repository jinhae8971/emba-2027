# EMBA 2027 봄학기 입학 준비 대시보드

서울대학교 EMBA · KAIST Executive MBA 2027학년도 봄학기 지원을 위한 개인용 준비 대시보드입니다.
빌드 도구 없이 동작하는 단일 HTML 파일이며, GitHub Pages 정적 호스팅으로 모바일에서도 접근할 수 있습니다.

**공개 주소:** https://jinhae8971.github.io/emba-2027/

## 구성

| 탭 | 내용 |
|---|---|
| 개요 & 리스크 | D-Day, 전체 타임라인, 최우선 액션 5, 진행률 |
| 학교 비교 | 지원자격·전형일정·재학생 프로필 비교 |
| 일정 & 서류 체크리스트 | 서울대 / KAIST / 공통 서류, 추천인 트래커 |
| 자기소개서 관리 | 스토리라인 6블록 작성 + 점검 체크리스트 + 텍스트 내보내기 |
| 비용 시뮬레이터 | 등록금·회사지원율·부대비용 기반 본인 실부담 계산 |
| 면접 Q&A 뱅크 | 17문항 + 답변 가이드 + 답변 스크립트 작성·내보내기 |

## 저장 방식

입력한 모든 값(체크박스, 추천인, 자기소개서, 면접 답변, 비용 설정)은 **브라우저 localStorage**에 저장됩니다.

- 서버로 전송되지 않으며 기기 밖으로 나가지 않습니다.
- 같은 기기·같은 브라우저에서만 유지됩니다. (PC와 휴대폰은 별도 저장)
- 시크릿 모드나 브라우저 데이터 삭제 시 사라집니다.
- 중요한 내용은 각 탭의 **내보내기** 버튼으로 텍스트를 복사해 별도 보관하세요.
- 헤더의 **기록 초기화** 버튼으로 전체 삭제할 수 있습니다.

## 모바일

- 반응형 레이아웃 (표는 가로 스크롤, 탭 바는 상단 고정)
- iOS Safari · Android Chrome에서 **홈 화면에 추가** 시 전체화면 앱처럼 실행됩니다 (`manifest.webmanifest`)

## 배포

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\setup_github.ps1
```

레포 생성(public) → 푸시 → Pages 활성화까지 자동 처리하며, 완료 후 원격 URL에서 토큰을 제거합니다.
`setup_github.ps1` 은 `.gitignore` 로 커밋에서 제외됩니다.

## 파일

```
index.html               대시보드 본체 (단일 파일, 외부 의존성 없음)
manifest.webmanifest     홈 화면 추가용 PWA 매니페스트
icon.svg                 앱 아이콘
setup_github.ps1         배포 스크립트 (커밋 제외)
```
